### Impact

`Claimed(user, …)` event affirms the user was paid. Recovery depends entirely on the orchestrator: the
run-20 analysis established that `InPlaceNFTStakerMigrator` has a rescue path while a bare

target pool** lose anything; on a migration into a freshly-deployed target every user has `pending == 0`
and nothing is misrouted.
